# Звіт до Лабораторної роботи №4
**Тема:** Git у терміналі

### Відповіді на контрольні запитання:

1. **Що змінилося у виводі git status після git add?**
   Файли перейшли зі стану Untracked у статус Changes to be committed (потрапили в індекс/Staging area).

2. **Що показує git diff?**
   Показує різницю між поточними змінами у робочій папці та останнім збереженим станом в індексі або коміті.

3. **Чим відрізняється git switch main від git merge?**
   `git switch main` переключає робочу папку на гілку main, а `git merge` об'єднує зміни з іншої гілки в поточну.

4. **Чому виник конфлікт і як ти його розв'язав?**
   Конфлікт виник через внесення різних змін в один рядок `index.html` у двох гілках. Я розв'язав його вручну, залишивши підсумковий заголовок `<h1>Дошка завдань: керуй завданнями</h1>` та видаливши службові розділювачі Git.
